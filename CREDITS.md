# Credits

## Libraries used

- [NumPy](https://numpy.org/) - all model math (logistic regression, losses, gradients, metrics) is implemented directly on NumPy arrays.
- [SciPy](https://scipy.org/) - `scipy.optimize.linprog` / `scipy.optimize.milp` (HiGHS solver) for the analyst review-queue allocation. Nothing else from SciPy is used for modeling.
- [pandas](https://pandas.pydata.org/) - tabular container for the synthetic transaction data and result tables.
- [Matplotlib](https://matplotlib.org/) - all figures and the executive PDF (`PdfPages`).
- [openpyxl](https://openpyxl.readthedocs.io/) - Excel workbook export.
- [HiGHS](https://highs.dev/) - the LP/MILP engine that SciPy wraps.

Deliberately **not** used: scikit-learn, XGBoost, PyTorch. Every method here
(logistic regression, focal loss, Platt scaling, PR-AUC/ROC-AUC/Brier/ECE) is
written from scratch in NumPy so the math is inspectable and unit-tested.

## Methods and references

- Class-weighted binary cross-entropy: standard practice for imbalanced classification.
- Focal loss: Lin, Goyal, Girshick, He, Dollar, "Focal Loss for Dense Object Detection", ICCV 2017.
- Platt scaling (with the original target-smoothing): Platt, "Probabilistic Outputs for Support Vector Machines...", 1999.
- Expected Calibration Error and reliability diagrams: Naeini, Cooper, Hauskrecht, AAAI 2015; Guo, Pleiss, Sun, Weinberger, ICML 2017.
- Precision-Recall analysis under class imbalance: Davis and Goadrich, "The Relationship Between Precision-Recall and ROC Curves", ICML 2006; Saito and Rehmsmeier, PLOS ONE 2015.

## Data

No external dataset is used. All transactions are generated by a seeded
synthetic generator in `fdo/data.py`; fraud patterns, label noise and drift
are constructed and documented there. Any resemblance to real merchants or
customers is coincidental.
